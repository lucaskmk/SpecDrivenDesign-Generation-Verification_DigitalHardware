# ULA MIPS de 32 bits

Implementacao orientada por especificacao da ULA combinacional do datapath
MIPS classico.

## Execucao

Com GHDL e cocotb instalados, execute:

```powershell
make -C test SIM=ghdl
```

Os artefatos de especificacao, arquitetura, implementacao, verificacao e
relatorio ficam todos nesta pasta.
